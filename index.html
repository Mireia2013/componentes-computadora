GUÍA DE INFORMÁTICA

Los componentes de una computadora

Conoce las piezas que hacen posible que un ordenador procese información, almacene archivos, muestre imágenes y se comunique con el mundo.

Un ordenador combina hardware (partes físicas) y software (programas).

1. ¿Qué es el hardware?

El hardware es el conjunto de elementos físicos de un equipo: se pueden tocar, conectar o sustituir. El software son los programas e instrucciones que indican al hardware qué debe hacer. Ambos trabajan juntos.

Idea clave: la CPU procesa instrucciones, la memoria RAM mantiene temporalmente los datos en uso y el almacenamiento conserva la información incluso cuando apagamos el equipo.

Estas piezas suelen encontrarse dentro de la torre o integradas en el portátil. La tabla resume su función y un ejemplo de uso.

4. ¿Cómo trabajan juntos?

Al abrir un programa, el sistema carga parte de sus datos desde el SSD o HDD a la RAM. La CPU procesa las instrucciones y la GPU prepara los gráficos que se muestran en el monitor. La placa base permite la comunicación y la fuente suministra energía.

EtapaComponente implicadoQué ocurre
1. EncendidoFuente y placa baseLa energía llega a los circuitos y el equipo inicia el sistema.
2. CargaSSD/HDD y RAMLos programas y datos necesarios se cargan en memoria.
3. ProcesoCPUSe ejecutan instrucciones y cálculos.
4. ImagenGPU y monitorSe genera y muestra el resultado visual.
Consejo: antes de limpiar o manipular el interior de un ordenador, apágalo, desconéctalo de la corriente y pide ayuda a una persona adulta o a un técnico si no tienes experiencia.
